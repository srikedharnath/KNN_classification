# KNN_classification


# K-Nearest Neighbors (KNN) Classification Project

## Project Overview
This project demonstrates the implementation of the K-Nearest Neighbors (KNN) Classification algorithm using Python and Streamlit.

The model predicts the class/category of data based on the nearest neighboring data points.

---

## Machine Learning Type
- Supervised Learning
- Classification
- K-Nearest Neighbors (KNN)

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

---

## Dataset
The project uses a classification dataset for training and prediction.

Example:
- Iris Dataset

---

## Features Used
Some common features include:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## Target Variable
The target variable contains class labels such as:
- Setosa
- Versicolor
- Virginica

---

## Algorithm Used
```python
KNeighborsClassifier()
```

KNN works by finding the nearest neighbors and predicting the majority class.
